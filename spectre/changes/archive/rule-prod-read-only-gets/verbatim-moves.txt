\## What stays open
A public, read-only HTTP request to a production URL: `curl` with `GET` or `HEAD`, no token, no cookie, no credentials of any kind, against a URL anyone on the internet can load — a page, a static asset, a response header, a status code.
Anything carrying credentials, any other method, or any non-public endpoint stays closed.
