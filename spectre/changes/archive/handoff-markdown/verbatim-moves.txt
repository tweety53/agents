# New rule: handoff blocks print as rendered Markdown (pipeline.md, Handoff output).
**A block is printed as rendered Markdown, never inside a code fence.
Each `**Field:** value` line is printed as a list item (`- **Field:** value`), since consecutive plain lines fold into one paragraph, and a path, branch or change name inside a value is inline code.
