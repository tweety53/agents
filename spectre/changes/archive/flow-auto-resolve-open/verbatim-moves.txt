# Operator instruction 2026-10-26: resolve every open item in-run (flow-auto-resolve-open).
**A determinism fix whose flake does not reproduce is not committed.
A defect whose commit the review drops is deferred, as a `big` one is: the parent runs `<agents repo>/scripts/pipeline-fix.sh drop <worktree>`, landing nothing.
A fix for a failure that does not recur on every run is a determinism fix, held to the PROOF RUNS paragraph above: the failure is shown returning with the fix reverted before the fix is committed, and a fix whose failure never returns is not committed.
A second non-zero exit from the same command is the branch's own defect and takes **The loop** (`skills/flow/verify-fix-loop.md`) once the whole list has run; where the environment itself failed — a missing build prerequisite — it ends the turn with `## Question` naming the command and its output, verbatim.
When the task's runs reproducing a flake, sized as the PROOF RUNS paragraph (`skills/flow/implement.md`) sizes them, see no failure without the fix, the fix is dropped: the task's one commit carries its reproduction test alone, no production change, its body stating the measured rate — runs and failures — in place of a fix for a flake nobody saw, and the task ticks through `close-task.sh <canonical-worktree> <name> <merge-base> <n>:<that commit's sha>` as any task.
**A child's hand-back never reaches the operator as an ask.
**An observed failure is never closed as "not reproduced".
**Every case the pass returns is a deliverable, landed on `<agents repo>` `main` before the report is:** `land-self-review-report.sh` refuses a report whose case line names no folder, or one absent from `<agents repo>` origin/main (`LAND-CASE-MISSING`).
**No block, and no run's final report, carries an open item for the operator** — a spot-check, a "your call", a deferred defect, an unreproduced failure, an unwritten case: each is resolved in the run before it hands off.
**Nothing else is ever deferred** — not "after the loop", not to the self-review, not to the operator: a non-`big` fix lands before the run's final report, and `integrate-change.sh commit` stops on a `deferred` line under 60 files.
A defect whose commit the review drops is re-planned: the parent runs `<agents repo>/scripts/pipeline-fix.sh drop <worktree>`, landing nothing, and opens a fresh loop on it, its planner carrying the review's objection.
A fixer's or implementer's "please spot-check", "your call" or any decision its report leaves open is resolved inside the run: a check it asks for — a regenerated golden or snapshot among them — is made by the loop's reviewer, its dispatch naming each regenerated file and the one change each may carry; a decision left over is taken by its recommended option by the parent and recorded as below, never listed as open.
One still unreproduced after runs sized as that paragraph sizes them is fixed anyway: every source of nondeterminism the trace names as a candidate — a container readiness wait, a shared port, an unpinned clock or order — is fixed at its source, each with a forced reproduction as its evidence (the candidate made to fail on purpose, a delay or a fault injected, failing the test without the fix and passing with it).
The fixer reproduces it under the conditions of the run that failed — the same concurrent load and the full-suite ordering, never the test alone or classes run one after another — and keeps every failing run's result files (the `result files:` and `full output:` paths `run-verify-list.sh` prints, or the JUnit XMLs and logs copied out by hand) before the next run overwrites them.
The one exception is a decision only the operator can make — outward-facing or irreversible with no recommended option (**What still stops**, `skills/flow-contracts/operator-prompts-auto-resolution.md`) — carried on the `**Decisions:**` line.
The task ticks through `close-task.sh <canonical-worktree> <name> <merge-base> <n>:<that commit's sha>` as any task.
The task's one commit carries those fixes and its body states the measured rate — runs and failures — and each forced reproduction; a fixer that names no candidate has not finished the trace, and is sent back to it.
This rule is canonical for every fixer of a test failure a run saw — this loop's, a full-suite fix's, a self-review loop's.
