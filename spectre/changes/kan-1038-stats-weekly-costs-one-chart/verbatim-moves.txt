# kan-1038: new plan-visual-prototype checklist item, intended new text
**A visible change is prototyped before its design is approved** (`plan-visual-prototype`, kan-1038).
A change with nothing visible builds none.
On a harness without the Artifact tool, write the file and give the operator its absolute path.
Save the approved file under `<project>-worktrees/<name>/.superpowers/sdd/` and cite it, with its Artifact URL, from `design.md`'s `## Context` as the spec the implementation and `flow.visual-verify` compare against.
When the change can alter what a user sees — a page, a view, a chart, a dialog — and no mockup frame already specifies it, build a clickable prototype of the proposed result with sample data as a single HTML file, publish it with the Artifact tool, and iterate it on the operator's feedback each round until they approve; that approval is the convergence confirm's **approve the design and move on** (**Convergence**, below).
