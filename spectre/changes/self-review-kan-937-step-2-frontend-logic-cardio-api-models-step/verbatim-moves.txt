# Self-review fix (task 1): a fix run runs the unfinished-work guard on itself before its handoff.
A missing verdict line or an exit 2 is reported and stops the run at the state it read.
An `OUTSTANDING:` line is this run's own unfinished work: finish what its breakdown names — a missing dispatch or review is run and recorded, never recorded after the fact for work that did not run — and run the guard again; the state is written only once every worktree prints `CLEAR:`.
# Self-review fix (task 3): the literal ## Merge order entry syntax spectre validate accepts.
\## Merge order
**Each `## Merge order` entry is a numbered line naming its repository in backticks** — `spectre validate` refuses a bare `1.
# Self-review fix (task 5): the begin-before-the-work rule covers every inline row, not only an inline fix.
An inline fix's `dispatch begin` is recorded when the parent starts the fix, before its first edit, and its `dispatch end` once the fix commit lands — never the two together, which records the fix as taking no time.
Every inline row's `dispatch begin` is recorded when the parent starts that work, before its first edit, and its `dispatch end` once the work's commit lands — never the two together, which records the work as taking no time; `flow record dispatch end` refuses an inline row closed under ten seconds after its begin when it carries no `-tokens` report.
