# KAN-1036, 2026-10-26: angle 8's late-round-miss paragraph, listed as check-verbatim-moves.sh prints it.
A **late-round miss** — a finding a slot first raises in round 2 or later on a hunk that same slot already reviewed, unchanged, in an earlier round — is traced to why the earlier rounds missed it, whatever its severity: the pass compares that slot's earlier dispatches with the round that raised it — the slot's reviewer prompt file at the change's merge base, the diff each was given, the findings it returned.
A generic instruction gap is a `reviewer` miss case whose `why_picked` names the rounds that missed it; any other cause — a re-run shown only the delta, or reviewer variance the bundle cannot explain — is an angle-8 finding naming that cause, classified by step 3's classification.
