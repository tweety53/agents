# pipeline-fix-11: the operator asked that a finished run leave nothing still open; these sentences add that rule.
"Not traced", "unverified" or a cause left unknown is never a classification: such a finding goes to step 3's planner as a non-`big` finding whose plan opens on the trace, never into the report or into the run's final report as an open item.
**Every suspected defect is traced to a verdict before the pass returns it.
**The Finished handoff, and the run's final report beside it, carry no open item** — nothing "still open", unverified or untraced.
Reproduced, it is fixable, `big` or not; disproved, it is `noted`, the evidence that disproved it in its line.
The final report carries no open item, per the Finished handoff rule in `skills/flow/cleanup.md`.
