# Deferred self-review via a saved-and-deleted context bundle — research notes

Source: KAN-512

## 1. What step 9 does today, and where the ticket's picture is off

Run 2's step 9 (`skills/flow/archive.md`, canonical procedure in
`skills/flow-contracts/finish-contract-run2.md`) runs inside `<landing-worktree>` on
`chore/archive-<name>`, after `FINISHED` is written. It resolves `## self review` from the main
checkout (`run` / `skip` / absent → the two-option skip prompt), invokes
`gather-self-review-context.sh <archived-change-path> <name> <state-dir> <landing-worktree>`, pipes
the bundle into one subagent on `SELF_REVIEW_MODEL` with a `Model:` handshake and an `opus`
fallback, receives the five-angle body back, drives the filing-and-rating `AskUserQuestion`
itself, writes `docs/self-review/<name>-self-review.md`, commits it on the archive branch, and
step 10 pushes the archive commit and the report together. Step 11 then removes the landing
worktree. `flow.self-review` is marked `begin`/`end -outcome completed` around the whole step;
the handoff carries `**Self-review:** <path> (rating: <n>/5) | skipped | skipped — project default`.

Three facts the ticket does not state, each of which shaped a decision below:

- **The four sources are the ledger, the panel record, the archived `tasks.md` and `git log
  --stat`** (`LEDGER_LABEL`/`PANEL_LABEL`/`TASKS_LABEL`/`GITLOG_LABEL` in the script).
  `design.md` is not one of them, for the same-run pass either.
- **`.superpowers/` is gitignored** in this repository, so the ticket's suggested
  `<project>/.superpowers/sdd/` home would make the bundle local-only and invisible.
- **`check-self-review-report.sh` scans every top-level `*.md` under `docs/self-review/`**
  (`find "$TARGET" -maxdepth 1 -type f -name '*.md'`), and a file with none of the five angle
  headings is an undeclared-zero coverage violation, so the bundle cannot sit there unannounced.

The verify reports the ticket names (`<abs-worktree>/.superpowers/sdd/verify-report-<key>.md`)
are removed with the apply worktree at run 2 step 5, before step 9 exists — no gather script can
ever include them. The only holder of that narrative is the session that lived it.

Today's real behaviour in the two projects that matter: agents and gymie both set
`## self review` to `skip` (gymie since f772c1e, 2026-09-10, the day after the KAN-459 run the
ticket cites). Deferral replaces "never" with "later", which is the use case.

## 2. The bundle: one committed file beside the report it becomes

`<project>/docs/self-review/<name>-context.md`, written by step 9 physically under
`<landing-worktree>`, committed on `chore/archive-<name>` with subject
`docs(self-review): <name> self-review context bundle`, carried by step 10's push exactly as the
report is today. "Self-review pending" is derived from that file existing — no new state field,
no new stage outcome, no store write. The deferred pass deletes it in the same commit that adds the
report, so a leftover is a visible tracked file, not a hidden local one.

Contents, in order: the gather script's output verbatim (its header line and four sections), then
`## design.md` holding the archived `design.md` verbatim, then `## Session narrative` holding the
archived `narrative.md` (section 4) followed by one paragraph the step-9 session appends for run 2
itself. One file per change, as the ticket asks.

`check-self-review-report.sh`'s find gains `-not -name '*-context.md'`, with one harness case
proving a bundle beside a compliant report is neither checked nor a coverage violation.

Rejected: `.superpowers/sdd/` (gitignored, invisible, lost on another clone, and needs staleness
handling the committed form gets from `git status` for free); `docs/self-review/pending/`
(no guard edit, but the bundle lives one level away from the report and the registry row would
name two directories).

## 3. Choosing to defer

`## self review` accepts a third literal, `defer`; the absent-key prompt gains a third option:

> **Run self-review for this change?**
> - **Yes — run it** *(default, recommended)*
> - **Defer — save the bundle for `/flow-self-review`**
> - **No — skip**

On `defer`, step 9 gathers, writes and commits the bundle, dispatches nothing, and ends
`flow.self-review` with `-outcome completed` exactly as `skip` does — nothing distinguishes the
deferred run in the store, deliberately: the bundle file is the record, and a store outcome would
be a second copy of it. The handoff's `Self-review` line gains
`deferred — docs/self-review/<name>-context.md`.

`/flow-fast` skips step 9 entirely and is untouched.

## 4. The narrative: every invocation appends, the archive carries it

`<changeRoot>/narrative.md` — under `spectre/changes/<name>/`, so `commit-split.sh`'s planning
pathspec already commits it as part of `chore(spectre): plan and session records`, `spectre
archive` moves it with the change, and the registry's **Change directory** row already covers
it. Two append points, each one dated `## <YYYY-MM-DD> — <run kind>` heading plus free prose of
what that session observed — problems hit, workarounds, time sinks, environment gaps, operator
decisions taken mid-run, nothing the ledger or panel record already holds:

- `flow.write-in-progress` (`skills/flow/verify-and-handoff.md`) — every creating and fix run,
  written before the state file so the run's own commit carries it.
- `flow.preserve-sessions` (`skills/flow/integrate.md`) — run 1, written before the branch is
  reshaped so the planning commit carries it.

Run 2 has no commit of its own that reaches the change directory, so the step-9 session writes
its paragraph straight into the bundle's `## Session narrative` section instead. A change whose
implementation predates this rule has no `narrative.md`; the bundle then says
`narrative.md: absent — change predates the narrative rule` in that section rather than an empty
heading.

Rejected: a narrative written by the step-9 session alone. That session is the integrate/archive
invocation and usually never ran implement or verify, so it would reproduce exactly the gap the
ticket's caveat describes (KAN-497's verify saga was lived by an earlier invocation).

## 5. `/flow-self-review <name>` — standalone, inline, on the session's own model

A new skill, `skills/flow-self-review/SKILL.md`, with the two command stubs
`commands/flow-self-review.md` and `commands-claude/flow-self-review.md`, shaped like
`/flow-settings`: **standalone, not a pipeline stage** — no state file, no `flow stage` mark, no
dispatch record. The operator picks the model with `/model` before invoking it; that is the whole
"stronger model" mechanism. The reasoning pass runs **inline in the session**, so the subagent
dispatch, the `Model:` handshake and the `opus` fallback of the same-run pass do not exist here,
and the session drives `AskUserQuestion` itself as it already must.

Procedure, run from the project's main checkout on `<default-branch>`:

1. Resolve `<bundle>` as `<project>/docs/self-review/<name>-context.md`. Absent: print every
   `docs/self-review/*-context.md` present (or `none pending`) and stop. Checkout not on
   `<default-branch>`: print the branch and stop.
2. Read the bundle. Run the five angles (the same table as run 2's step 9, `flow-` labels) over it;
   every angle produces zero or more findings and an empty angle says so.
3. Explain every finding in the message body, then the one filing-and-rating `AskUserQuestion`
   (same shape as step 9, overflow rule included). File chosen findings per **Labels on issues the
   pipeline creates** (`skills/flow-contracts/jira-integration.md`), each with its angle label;
   `## jira` absent or `none`, or no Atlassian tooling → `⚠ Jira: skipped — <reason>` and the
   finding is recorded `declined`.
4. Write `<project>/docs/self-review/<name>-self-review.md` in the report shape
   `check-self-review-report.sh` checks, plus one line under the title:
   `**Deferred:** reasoning pass run on <model named in this session's own system prompt> from
   <bundle path>` — the parity caveat made explicit, as the ticket asks.
5. Delete the bundle. Run `scripts/check-self-review-report.sh` when the project has it. Commit
   both paths in one commit, `docs(self-review): <name> self-review report`; `git pull --rebase
   origin <default-branch>`; `git push origin <default-branch>`. A rejected push leaves the
   commit local and the run says so — never retried around
   (`~/.claude/rules/no-direct-pushes-to-main.md`).
6. End by naming the report path, the rating and the keys filed.

The temporary-artifacts registry gains one row: **Self-review context bundle** · created by run 2
step 9 on `defer` · `<project>/docs/self-review/<name>-context.md`, committed on
`chore/archive-<name>` · removed by `/flow-self-review <name>`, in the report commit.

Every guard that enumerates skills or command stubs by name needs the new files declared:
`check-contract-budget.sh` (three budget rows), `check-references.sh`
(`EXPECTED_ZERO_COMMAND_DISPATCH_STUBS`, two entries), `check-installed-citations.sh`
(`declare_if_present`, two entries), `check-guard-symlinks.sh` (`declare_if_present
"flow-self-review"`), `check-stage-mark-calls.sh` (`EXPECTED_ZERO_FILES`, the skill). `setup.sh`
installs skills and commands by glob, so nothing there. `CLAUDE.md`, `AGENTS.md` and `README.md`
each gain the skill-index row or tree line.

## Step-by-step breakdown

### `defer` literal and third prompt option

**What:** `## self review` accepts `run` / `skip` / `defer`; the absent-key prompt at run 2 step 9
gains a **Defer** option.
**Why:** The choice has to exist at the same two places the run/skip choice exists today, in the
same shape, or a project cannot opt in.
**Uses:** `skills/flow-contracts/project-configuration.md`, `skills/flow/archive.md`,
`skills/flow-contracts/finish-contract-run2.md`, `project-get.sh`.

### The bundle write at step 9

**What:** On `defer`, step 9 writes `docs/self-review/<name>-context.md` — script output, archived
`design.md`, archived `narrative.md` plus the run-2 paragraph — commits it on the archive branch,
dispatches nothing, and the handoff says `deferred — <path>`.
**Why:** One committed file is the whole pending state, carried by the push step 10 already makes.
**Uses:** `gather-self-review-context.sh`, `skills/flow/archive.md`,
`skills/flow-contracts/handoff-blocks.md`, `skills/flow-contracts/artifacts-registry.md`.

### Report guard skips bundles

**What:** `check-self-review-report.sh`'s find excludes `*-context.md`; one harness case.
**Why:** The guard would otherwise fail the archive commit's own branch on an unrecognisable report.
**Uses:** `scripts/check-self-review-report.sh`, `scripts/test-check-self-review-report.sh`.

### `narrative.md` appended per invocation

**What:** `<changeRoot>/narrative.md`, a dated paragraph per run, appended at
`flow.write-in-progress` and `flow.preserve-sessions`.
**Why:** The session that lived a verify saga or a merge conflict is rarely the one at step 9; the
archive is the only place that memory survives to a deferred pass.
**Uses:** `skills/flow/verify-and-handoff.md`, `skills/flow/integrate.md`, `commit-split.sh`'s
existing planning pathspec, `spectre archive`.

### `/flow-self-review <name>`

**What:** A standalone skill plus two command stubs: read the bundle, run the five angles inline,
file and rate, write the report with a `**Deferred:**` line, delete the bundle, one commit on the
default branch, pull, push.
**Why:** The session's own model is the stronger model; no dispatch means no handshake, no
fallback, and a command that fits the `/flow-settings` shape the guards already know.
**Uses:** `skills/flow-self-review/SKILL.md`, `commands/flow-self-review.md`,
`commands-claude/flow-self-review.md`, `skills/flow-contracts/jira-integration.md`,
`skills/flow-contracts/operator-prompts.md`, `scripts/check-self-review-report.sh`, `git`.

### Guard and index declarations

**What:** Budget rows, expected-zero and `declare_if_present` entries for the three new files, and
the skill-index rows in `CLAUDE.md`, `AGENTS.md`, `README.md`.
**Why:** Every guard that enumerates by name fails on an undeclared file; the index is where an
operator finds the command.
**Uses:** `scripts/check-contract-budget.sh`, `scripts/check-references.sh`,
`scripts/check-installed-citations.sh`, `scripts/check-guard-symlinks.sh`,
`scripts/check-stage-mark-calls.sh`.

### Project configs set to `defer`

**What:** agents' and gymie's `.flow/project.md` `## self review` bodies become `defer`; the two
frontend repos by hand after landing.
**Why:** The operator asked for deferral everywhere; only agents and its declared peer are
reachable from this change's worktrees.
**Uses:** `/Users/tweety53/Projects/agents/.flow/project.md`,
`/Users/tweety53/Projects/gymie/.flow/project.md`, `spectre/peers`.
