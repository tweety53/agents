Parse that diff by state: a `diff --git` line opens a file header, which ends at its first `@@` line; inside the header `--- a/<p>` and `+++ b/<p>` name the path (the `---` side for a deletion, whose `+++` is `/dev/null`); each `@@ -<o>[,<n>] +<n>[,<m>] @@` sets the old and new line counters; after it a line opening `+` is an added line at the new counter and one opening `-` a removed line at the old counter. A reason is the first match in diff order, `<path>:<line> <rule>` for a content rule and `<path> <rule>` for a path rule, `<rule>` a short fixed name of the rule that matched. Lockfiles are `go.sum`, `package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `Cargo.lock` and `*.lockfile`. Exit 2, nothing on stdout, with a `Reason(env, …)` code, on no arguments or an odd count, a pair `panelValidateWorktree` refuses, or a failed git call.
