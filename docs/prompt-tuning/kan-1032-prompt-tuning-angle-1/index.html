+func lpPromptTuningOnly(env Env, git, repo, branch string) bool {

+		return false
+	}
+	for _, p := range paths {
+		if !strings.HasPrefix(p, "docs/prompt-tuning/") {
+			return false
+		}
+	}
+	return true

Why picked

1. Defect class: a decision built from several clauses (operands of a compound condition, a bound, the members of an accepted set) is tested only end to end, so a mutant that drops or loosens one clause survives. 2. The implementer instructions cover proof-by-breaking only for tests that assert on configuration or file content: "When this task's tests assert on configuration or file content — a guard script, an embedded config, a fixture file — a passing run alone is not evidence: break the property the assertion protects ... the failing run against the broken state is the evidence." The per-clause demand exists only in the fix subagent's MUTATION PROOF, which a first implementation never receives. 3. It generalises: this run's round 0 raised four Important single-clause survivors in three separate decisions (an emptiness operand, a branch-prefix gate, a count, one member of an enum), and the store's panel records show the same class in other changes (for example kan-918's F2-F11 and F20 and kan-1033's F5 and F10, all Important mutation findings on untested branches or bounds), each costing a fix round. 4. It is not patch accretion: it states one principle (every clause of a decision is pinned by a test that fails without it), names no construct from this task, and holds in any language and on any layer.
